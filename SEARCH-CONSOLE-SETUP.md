# Google Search setup

1. Add `https://gstreconciliation.in/` as a Domain or URL-prefix property in Google Search Console.
2. Verify ownership using the method Google provides for your property.
3. Submit `https://gstreconciliation.in/sitemap.xml`.
4. Inspect the homepage and important article/tool URLs and request indexing where appropriate.

The website includes a robots.txt, sitemap.xml, canonical URLs, descriptive titles and structured data. Search rankings are determined by Google's systems; no HTML file can guarantee a #1 position.
